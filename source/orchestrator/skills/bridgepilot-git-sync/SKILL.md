# bridgepilot-git-sync

由当前控制对话编排，复用各项目实际安装的 [git-sync](../git-sync/SKILL.md) 普通模式。用户调用本技能授权本轮所选项目的普通同步；咨询、查看名单或创建技能本身不授权同步。拒绝 release 参数，不将其静默当作项目名或普通同步。

## 定位与范围

读取相邻 [bridgepilot](../bridgepilot/SKILL.md) 的本机绑定，按其流程核验实际 home、skill-status 和 bp-sqlite-status-v1，再调用只读 status。不能将当前目录或发行包猜作私有 workspace。本技能是本地扩展；现有 BP skill-status 仅核验其已有入口，不证明本扩展已纳入 BP 安装器。

用本技能 `scripts/list_projects.py` 读取绑定指向的 SQLite，默认列出全部登记项目；指定子集时重复传 `--project <精确项目 ID 或名称>`。示例（脚本路径以本技能实际目录为准）：

```text
python <本技能目录>/scripts/list_projects.py
python <本技能目录>/scripts/list_projects.py --project StratusAgent --project HoldemTrainer
```

脚本只读、无迁移，不访问原生聊天或凭据。缺库、旧 schema、未知或歧义名称均停止范围解析，不能降级为全量同步。项目名单和本机绑定来自数据库，不硬编码目录、仓库或机器 ID。未登记项目先报告缺口，不自动登记。

依据输出的暂停标记、custody、runs 和 operations 核对本机控制权及在途操作；暂停、交接冻结、活跃或 Unknown 执行只阻断相应项目，不抢占或自动恢复。不确定状态先沿 BP 入口核销；缺本机唯一绑定、缺目录或非本机 host 的项目标记未执行。数据库未登记其他编辑者，仍须核对当前会话已知的并行写入。

## 并行执行

派发前核对各绑定的真实 Git 根、仓库身份及实际推送目标，读取项目 AGENTS 和必要入口。登记路径发生漂移不猜替代目录。同仓库的重复绑定、符号链接及共享 Git common-dir 的 worktree 只允许一个执行者；含义不明先报告，不并行修改共享 Git 状态。

本次调用允许使用子 agent 分担独立项目，每个执行者只负责一个仓库，沿其 git-sync 完成整个审阅与同步闭环。按当前可用并发槽位有界派发，超出容量排队；没有子 agent 能力时明确说明并顺序执行，不声称并行。使用当前模型和推理设置，不创建用户侧新聊天、heartbeat 或独立服务。

每个执行者接收：项目 ID、真实目录、仓库、所选范围、本轮普通同步授权、禁止 release，以及失败时保留现场的要求。它必须读取自己的项目规则与实际 git-sync，不以主对话的摘要替代差异审阅。敏感内容、私有远端和精确发布范围等项目既有约束仍适用；实际缺授权时暂停该项目并汇报，其他项目继续。

单项目沿 git-sync 的受管入口完成 preflight、真实 diff 审阅、中文提交消息、提交、推送及独立核验。不得手工拼 Git 写操作替代受管流程，不隐式安装工具、升级骨架、升版或执行 release，也不自动修复业务、补验收或开展无关测试。没有差异时允许 no-op，仍按受管结果判断是否存在待推送提交。

任一项目失败保留工作区、冲突、stash 和已生成提交，继续其余独立项目。push 失败不重跑整个同步、不重做提交、不强推；结果未知先核销。平台强制确认和真实敏感范围缺口交用户处理，不能由其他 agent 自称获准代替。

## 汇总

等待已派发执行者结束并核对各自真实收据；后续新增项目不自动加入当前批次。按项目汇总：提交摘要与 commit、推送成功／no-op／失败／未执行、实际推送目标、工作区与 stash、阻点。没有独立核验的结果明确标注未验证；模型 completed 不等于同步成功。

本地结果摘要不是第二份 BP 任务档案。不为凑状态创建任务、Run 或 Released，不用普通同步核销现有开发任务；已有 BP Run 的记录按其原有流程处理，不伪造收据。交付说明本轮为普通同步，列出失败项目的具体继续条件。
