# Forge 项目级工作流分发迁移

2026-11-06，用户授权开发并确认整体预算：最多 4 小时、约 80,000 token，主对话实施，1 个只读独立复核 Agent，1 轮集中验证和 1 轮必要修复复测。范围为仓库内实现和隔离迁移验证。真实项目部署、本机用户级退役、提交推送和发布分别授权。

项目安装通用 Skill、维护入口及原有项目工具。用户级保留用户 `AGENTS.md` 和原生 Memory Hook 所需执行器。BP 专用入口属于 BP 安装范围。

| 阶段 | 工作与完成条件 |
|---|---|
| P0 | 将通用 Skill 和维护文件登记为显式项目资产，生成工厂镜像。验证新装、重复应用、已知内容更新和未知同名文件保护。 |
| P1 | 使用固定官方来源和已准备 CLI／Hook 进行 `project-sync`，迁移 BP 调用路径。验证用户目录没有 Forge 通用安装时仍能引导新装与旧项目升级。 |
| P2 | 将 Memory Hook 切换到专用执行器。验证原启用状态、第三方 Hook、既有配置和同步状态的保留，以及失败恢复。 |
| P3 | 在隔离用户目录验证已登记全局 Forge 资产的退役、冲突和中断恢复。项目级入口和 Memory 均通过后，才进入真实部署决策。 |

传播边界：通用实现属于产品层，工厂镜像随项目资产生成。用户原生 Memory 数据与项目自有 Hook、Skill 独立保留。分发作用域变更按 Forge 不兼容变更评估；BP 维护入口资产按原生交付范围核对。
